# Lumiverse-Extensions
Just a list of all Lumiverse extensions, sorted by creator then alphabetically.

## Beeopo
### [Rewrite](https://github.com/Beeopo/Lumiverse-Rewrite)
Rewrite highlighted/selected text
`https://github.com/Beeopo/Lumiverse-Rewrite`

## Cfigure
### [Prompt Viewer](https://github.com/cfigure/Lumiverse-prompt-viewer)
View fully assembled prompts after they've been sent to the LLM
`https://github.com/cfigure/Lumiverse-prompt-viewer`

## Creature
### [Canvas](https://github.com/j-dandelion/Lumiverse-Canvas)
Improved UI, including moving extensions to a second sidebar on desktop
`https://github.com/j-dandelion/Lumiverse-Canvas`

### [Chronicle](https://github.com/j-dandelion/Lumiverse-Chronicle)
Lorebook memory system similar to ST's MemoryBooks
`https://github.com/j-dandelion/Lumiverse-Chronicle`

## EmpeQ
### [Multi Image Gen](https://github.com/EmpeQ17/Lumiverse-Auto-Image-Gen)
Send multiple image gen requests with a single llm response
`https://github.com/EmpeQ17/Lumiverse-Auto-Image-Gen`

## Japolino
### [Inlay](https://github.com/japolino/inlay-illustrator)
Context aware image gen
`https://github.com/japolino/inlay-illustrator`

## Kitty Lotus
### [Prism](https://github.com/kittyafterdark/Prism)

`https://github.com/kittyafterdark/Prism`

## Kxa
### [Notehaven](https://github.com/hans123m12m1/lumiverse-notehaven)
A notes extension similar to ObsidianMD
You can also set the floating button to a cute chibi of your OC :3 (or whatever image you want, idc)
`https://github.com/hans123m12m1/lumiverse-notehaven`
