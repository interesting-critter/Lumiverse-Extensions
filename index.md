## Notes

- **Renamed repository.** `Cue` was listed as `japolino/cue-visual-novel`, which no longer
  exists (HTTP 404, including via the GitHub API). The account's public repository list shows
  `japolino/cue-living-novel` ("Cue turns your Lumiverse chats into a living visual novel"),
  which is the same project. Documentation was collected from that canonical repository; the
  source list link has been updated to match.
- **Non-GitHub host.** `Swipe Scrubber` is hosted on Codeberg, not GitHub. Its Git repository
  was cloned directly from `codeberg.org`.
- **Promoted README.** `LumiAgent` and `LumiBooks` keep their README at `.github/README.md`
  rather than the repository root; it has been mirrored to `extensions/<slug>/README.md` with the
  original path recorded in the file's metadata header.
- **No upstream documentation.** `Character Nudges`, `Shitposting Chat Room` and
  `Spotify Controls` contain no Markdown documentation at the retrieved revision. Their
  directories contain a generated metadata stub instead.
- **Platform docs omitted.** `Greeting Image Generator` vendors 168 files of Lumiverse **platform**
  documentation under `docs/user-docs/` and `docs/developer-docs/` — backend and frontend API
  references, chatting, presets, world books, weaver, and so on. None of it describes the extension,
  and the extension's own README never links to it, so it was deliberately left out of the mirror.
  Only the extension's `README.md` is kept. Consult the source repository if you need the platform docs.
